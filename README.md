Проект «Умная таблица» — это реализация интерактивной таблицы для отображения и обработки данных о продажах. В ходе работы над проектом реализована модульная архитектура, позволяющая гибко расширять функционал, а также выполнен переход от работы с локальными данными к взаимодействию с внешним API. Проект охватывает два спринта: в шестом спринте реализована базовая функциональность таблицы, в седьмом — рефакторинг кода для работы с серверными данными.

# Функционал
В рамках проекта реализованы следующие возможности:

## Отображение данных в виде таблицы с динамической генерацией строк на основе шаблона.

- Пагинация — разбиение данных на страницы с возможностью переключения между ними, отображением текущего диапазона строк и общего количества записей.


- Сортировка — упорядочивание данных по выбранным полям (например, по дате или сумме покупки) с визуальным отображением направления сортировки.
- Фильтрация — отбор данных по заданным критериям (например, по продавцу) с использованием выпадающих списков и полей ввода.
- Поиск — поиск записей по ключевым словам в нескольких полях (дата, клиент, продавец).
- Работа с API — получение данных с сервера с передачей параметров поиска, фильтрации, сортировки и пагинации через query-параметры.
- Кеширование запросов — оптимизация работы с сервером за счёт сохранения результатов предыдущих запросов при неизменных параметрах.
- Архитектура и подход к разработке
Модульная архитектура


# Проект построен по модульному принципу: 
каждый функциональный блок (пагинация, сортировка, фильтрация, поиск) реализован в отдельном JS-модуле в директории src/components/. Все модули следуют единому шаблону инициализации




# Конвейер обработки данных
В шестом спринте данные обрабатывались локально по схеме:
Исходные данные → Поиск → Фильтрация → Сортировка → Пагинация → Вывод в таблицу.


# Обработка событий
## Для управления таблицей используется единая форма, охватывающая всю таблицу. Обрабатываются события:
```
`change` — изменение значений в полях формы;
`submit` — отправка формы (используется для сортировки и переключения страниц);
`reset` — сброс формы (с задержкой для корректного обновления состояния).
```
Все события сводятся к вызову единой функции перерисовки таблицы, что минимизирует количество обработчиков.






# Реализация по спринтам
Спринт 6: базовая реализация «умной» таблицы
На этом этапе была реализована работа с локальными данными. Основные задачи:

Вывод данных в таблицу — в файле src/components/table.js реализована генерация строк на основе шаблона с использованием функции cloneTemplate.
Пагинация — добавлен модуль pagination.js, который вычисляет количество страниц, отображает кнопки навигации и управляет диапазоном выводимых строк.
Сортировка — модуль sorting.js позволяет сортировать данные по выбранным полям с переключением направления сортировки.
Фильтрация — модуль filtering.js реализует фильтрацию данных на основе значений в полях формы.
Поиск — модуль searching.js добавляет возможность поиска по нескольким полям данных.
На этом этапе активно использовались вспомогательные функции из директории src/lib/ (например, для сравнения значений и сортировки коллекций).

#    Технологии и инструменты

# Как запустить проект
Клонируйте репозиторий.
Установите зависимости:
```
bash
npm install
```
Запустите проект в режиме разработки:
```
bash
npm run dev
```
Откройте в браузере ссылку, указанную в консоли.
